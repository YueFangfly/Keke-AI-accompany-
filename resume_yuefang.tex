% ─── DPDP ───
\projectentry{动态配送调度优化（DPDP）}{小组项目}{数学建模与仿真}{2025}

\begin{itemize}
  \item 针对校园外卖配送场景，建模\textbf{动态取送货问题}（DPDP），扩展经典 TSP/VRP 问题至实时动态订单环境，使用非齐次 Poisson 过程模拟时变订单到达（$\lambda(t)$: 0.3--1.5 单/分钟）
  \item 设计并对比两种调度策略：\textbf{最近骑手}（Nearest Driver, 贪心最近分配）与\textbf{准时制}（Just-in-Time, 基于 ACA 预测策略同步食物备好与骑手到达），通过离散事件仿真评估平均等待时间与骑手利用率
  \item 构建随机行驶时间模型：Euclidean 距离 $\times$ 1.417 路网修正 $\times$ 跨校区拥堵系数（$\alpha = 1.5$--$2.0$）+ 有界正态延迟（$\mathcal{N}(2.5,1)$, 截断至 [0,6] min），通过灵敏度分析确定最优车队规模（21--25 名骑手）
\end{itemize}

\projectentry{人群疏散建模：PDE 与 Agent-Based 方法比较}{毕业论文（小组项目）}{建模与仿真开发}{2026}

\begin{itemize}
  \item 参与撰写 25 页研究论文，对比 PDE 模型（Hughes 连续性方程，有限体积法离散化）与 Agent-Based 模型（SDE + Euler-Maruyama 离散化 + Brownian Motion 行为随机性），运行 100 次 Monte Carlo 模拟进行统计分析
  \item 量化分析出口布局优化，证明居中出口较角落出口减少 23--35\% 疏散时间；实现 M/Er/2 排队模型模拟出口瓶颈动力学，引入人群异质性建模（行动不便人群 $v_{\max} = 0.75$ m/s），对标英国 150 秒安全法规
\end{itemize}
